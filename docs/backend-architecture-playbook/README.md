# Backend Architecture Playbook

Цей розділ документації описує фактичну архітектуру бекенду в `src/` та правила її розвитку.

## Зміст

1. [`01-architecture-overview.md`](./01-architecture-overview.md) — огляд архітектури проєкту, потоку запиту, ролей модулів.
2. [`02-how-to-create-new-module.md`](./02-how-to-create-new-module.md) — покроковий гайд, як правильно додавати новий модуль.
3. [`03-shared-folder-guidelines.md`](./03-shared-folder-guidelines.md) — що таке `src/shared`, коли туди додавати код, а коли ні.

## Для кого

- Для розробників, які підключаються до проєкту.
- Для команди, щоб синхронізувати правила структури коду.
- Для рев’ю PR, щоб перевіряти архітектурні рішення за єдиними критеріями.
